# Calculate325

输入一个目标数字，程序给出等于它的算式。


## 求解

默认自带四个数字串

**325**  

**799** 

**325799** 

**114514**

选一个数字串，用它的数字做四则运算凑出目标值。例如用 `325` 凑 1000：

```
325 × 3 + 25 = 1000
```
可以自定义数字串

数字串自定义范围：0<x<100000000
