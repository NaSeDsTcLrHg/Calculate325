# Calculate325

输入一个目标数字，程序给出等于它的算式。

## 一、求解

选一个数字串，用它的数字做四则运算凑出目标值。例如用 `325` 凑 1000：

```
325 × 3 + 25 = 1000
```

## 二、随机生成

随机出一条又长又复杂的式子，化简后恰好等于 **325**。

![随机模式](docs/screenshot-random.png)

## 特色功能

- **五档难度**：L1 四则运算 → L5 多重积分 + 行列式 + 数论 + 嵌套上下限，层级严格递增。
- **双引擎校验**：每条式子由 C# 审计器和 Python 独立实现各算一遍，不一致就换种子重生成。
- **可验证陷阱**：有限域取模、离散期望、Fubini 换序、一阶 ODE，值恒为 1 但看着不像 1。
- **种子分层**：L1–L5 分别用 12/20/24/32/64 位种子，同一种子永远出同一条式子。
- **Zc 编码**：种子可用 `Z`/`C` 字母串显示（大小写即 0/1），选择会被记住，重启后仍生效。
- **历史与收藏**：自动落盘，可按等级筛选、点表头排序、复制公式 / 种子、保存 PNG。
- **逐条查看**：左右翻页按当前排序走，可缩放、拖动、复制。
- **四套皮肤**：含深色主题，子窗口标题栏跟随配色。
- **两种形态**：Windows 桌面版（WinForms + WPF 排版）与单文件离线浏览器版。
