计算325 Calculate325

给定数字 n，用所选数字串的连续重复（325325… / 799799… / 325799325799… / 114514114514…），插入运算符与括号，凑出一个结果正好等于 n 的算式。

数字串可多选：勾选的每一个都会各自算一遍，结果全部输出。数字顺序固定不可交换（可在高级选项里放开）；允许 + − × ÷、括号、小数点、后缀阶乘。

数字串：
高级选项

2 块通常 1 秒内出解；3 块以上属于深度搜索，可能触发时间预算（5 秒）而返回“未找到 + 保底构造”。

规则与算法说明

数字怎么用：整条算式的数字（从左到右读出来）必须是所选数字串的重复，恰好用完整块： 选 325 时 1 块 = 325、2 块 = 325325；选 114514 时 1 块 = 114514。 相邻数字之间不插运算符就拼成多位数，例如用 325 时 2 块可以写成 325×3+25（读作 3‑2‑5‑3‑2‑5）。

允许的操作：加减乘除、括号、小数点（如 3.25、32.5）、后缀阶乘 3!、(3+2)!； 阶乘只作用于非负整数，参数不超过上面设定的上限。

“有了 3 就必须有 2、5”：每一块都是完整的数字串，所以每个数字都会随整块一起用掉。

求解目标：先最少块数 → 再最少用数个数 → 再最短算式。

算法：区间动态规划（精确 BigInt 有理数，无浮点误差）。把数字串的每个子串、按“用了几个数”分轮， 像 dp(子串, 用几个数) 一样枚举所有切分与运算；轮数由小到大，命中即停。所有结果都再用一个独立的解析器复算一遍校验。

为什么有时直接给“保底构造”：为了限制组合爆炸，中间结果有幅度/分母上限并按轮限量保留简单值； 在给定块数内没找到更短算式时，程序会用 n = 数字串×q + r 递归拼出一个一定成立的式子输出。
