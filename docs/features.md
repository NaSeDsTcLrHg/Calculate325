# 可交互功能一览

按窗口列出能点的东西。共 5 个窗口 + 浏览器版。

## 主窗口

| 控件 | 作用 |
| --- | --- |
| 目标输入框 | 输入任意目标：`325`、`1000`、`3.25`、`-7` |
| 数字串下拉 | `325` / `799` / `325799` / `114514` / 自定义项 / 我全都要 |
| 自定义… | 新建自己的数字串（1–8 位） |
| 最多用几个块 | 限制用几个数字串拼 |
| 顺序 | 固定 `325325…` 或允许交换 `3/2/5` |
| 允许后缀阶乘 + 上限 | 开关阶乘并设最大值 |
| 允许小数点 | 允许出现小数 |
| 高级运算 → 5 个子勾选 | 乘方 / 根号 / 组合数 / gcd·mod / 行列式 |
| 求解 | 开始搜索并输出算式 |
| 复制算式 | 纯 ASCII / LaTeX / 导出 PNG 三选一 |
| 随机模式 | 打开随机窗口 |
| 皮肤下拉 | 切换 4 套主题 |

## 随机窗口

| 控件 | 作用 |
| --- | --- |
| 等级下拉 | L1 – L5 |
| 种子框 | 手动输入种子（每 4 位空格、每 32 位换行） |
| 随机生成 / 自定义 | 换随机种子 / 打开种子对话框 |
| 缩小 · 放大 · 复位 | 视图缩放；滚轮缩放、拖动平移、双击复位 |
| 复制 · 收藏 · 存图 | 复制 LaTeX / 收藏当前式子 / 导出 PNG |
| 历史 · 收藏夹 | 打开对应列表 |
| 快捷键 | `Ctrl+Enter` 重生成、`Ctrl+R` 换种子、`Esc` 关闭、种子框 `Enter` 生成 |

## 自定义种子窗口

| 控件 | 作用 |
| --- | --- |
| 数字模式 / Zc 模式 | 切换编码，切换即记住（重启仍生效） |
| 种子输入框 | 十进制或 `ZcZczc…` 字母串 |
| 预览框 | 每 32 位一行，实时刷新 |
| 随机种子 | 按当前等级生成合规种子 |
| 确定 / 取消 | — |

## 历史 / 收藏列表

| 控件 | 作用 |
| --- | --- |
| 等级筛选 | 全部 / L1–L5 |
| 表头 | 点击排序，再点反向（▲▼ 提示） |
| 行勾选框 | 多选 |
| 行内 查看 | 打开单条查看窗口 |
| 全选 / 取消全选 / 反选 / 清空 | 批量选择与清理 |
| 收藏选中 | 批量加入收藏（按 LaTeX 去重，仅历史模式） |
| 删除选中 / 取消收藏 | 批量移除（收藏模式显示为「取消收藏」） |
| 右键菜单 | 查看 / 复制 LaTeX / 复制种子 / 保存图片 PNG / 删除 |
| 双击行 | 直接查看 |

## 单条查看窗口

| 控件 | 作用 |
| --- | --- |
| 上一条 / 下一条（左右竖条） | 按当前列表排序翻页，到头自动禁用 |
| `←` `→` | 翻页；`Esc` 关闭 |
| 缩小 · 放大 · 复位 | 公式缩放 |
| 存图 · 复制种子 | 导出 PNG / 复制十进制种子 |
| 复制 · 收藏 · 关闭 | — |
| 种子框 | 跟随 Zc/十进制模式，可手动选中复制 |
| 顶部小字 | 提示当前列表排序方式 |

## 浏览器版

| 控件 | 作用 |
| --- | --- |
| 目标输入 + 示例标签 | 点击标签快速换目标 |
| 数字串 / 块数 / 顺序 | 同桌面版 |
| 阶乘上限 + 两个勾选 | 同桌面版 |
| 求解 | 输出算式 |
