# 随机模式设计

点击「随机模式」弹出新窗口，每次生成**一条**式子，化简后恰好等于 325。

## 等级

| 等级 | 种子 | 内容 |
| --- | --- | --- |
| L1 | 12 位 | 初等四则，不含微积分 |
| L2 | 20 位 | 单层积分 / 级数 / 极限 |
| L3 | 24 位 | 固定 4 层嵌套 |
| L4 | 32 位 | 5–9 层，多重积分、级数重排 |
| L5 | 64 位 | 10+ 层：矩阵行列式（2–6 阶）、数论函数、嵌套上下限 |

矩阵与数论只属于 L5；层级严格递增（L1 < L2 < L3 < L4 < L5）。

## 种子

- 每个等级固定长度，同一种子永远生成同一条式子；
- 两种显示编码：十进制，或 `Zc` 字母串（`Z`/`C` 交替，大小写表示 0/1，每 4 位空格、每 32 位换行）；
- 模式选择会落盘记住，重启后仍是上次选的编码。

## 结构

一条式子由「因子链」组成：每个因子带精确有理值，乘积必须严格等于目标。

- **经典模块**：`∫₀¹xᵖdx`、`∫₁^∞x⁻²dx`、交错级数、Wallis 乘积、留数积分……按等级筛选；
- **隐藏系数**：把 5、13、25 这类显眼常数藏进恒等变形（Vieta、复数模长、立方和、对数）；
- **陷阱层**：值恒等于 1 的可验证陷阱 —— 有限域取模、离散期望、Fubini 换序、一阶 ODE 的 FTC；
- **嵌套层**（L5，30%）：积分上下限本身是嵌套树，深度 1–3，模块值恒为 1。

## 视觉

LaTeX 由 WpfMath 排版，单行不折行；滚轮缩放、拖动平移、双击复位；导出 PNG 按大尺寸重渲染。

## 约束

- 不出现裸 325 / 650 / 13·25；
- 最外层只能是 lim / Σ / ∫ / 因子乘积 四选一；
- 不加入两套校验器都算不出的公式。
