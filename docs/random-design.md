# 随机模式设计（mhtml 层类型 + 混合嵌套 + LaTeX 预览）

> 目标：点击「随机模式」弹出**新窗口**，每次生成**一条**式子；
> L1 是简单初等函数；L2 是单层积分/极限/级数；L3/L4 可以把
> 单/二/三重积分、极限、级数、极限+积分、级数+积分、极限+级数、
> 等分布极限任意嵌套混合；值恰好等于 325。
> L5 自 2026-10-23 起改为**自然模型管线**（M1–M10），不再走“独立因子链”；
> 见 §7.2.8 与 `docs/l5-v2-design.md`。
> 随机窗口用 LaTeX 排版预览，主窗口保持原文本渲染。

## 2. 种子布局（L2-L4）

> 2026-10-23：**L5 不再使用下面的“类型位 + 家族/参数”布局**。L5 的 64 位种子
> 整体参与 SHA-256 子种子派生（`L5Pipeline.cs`），与 L2–L4 的位布局无关。
> 下面的规则只适用于 L2–L4。

种子长度 = `8 × level`：

```
前 2×level 位：各层的「类型位」（9 = 没有这一层）
后面每 3 位一组：[家族 1 位][参数 2 位]
```

- **第一位 = 最外层类型**；第二位 = 第二层类型；9 = 没有。
- 第一层必须有（第一位是 9 时强制改成 0）。
- L2 只取 1 个主层；L3 固定 3 个非 1 分析因子；L4 固定 4–5 个；L5 唯一含矩阵/数论。
- L4 按概率混合：30% 老版、10% 新版纯因子、60% 融合版；最外层随机为 lim / Σ / ∫ / 因子乘积。
- **以下 L5 条目是 v2 之前的记录**，保留作历史；当前 L5 见 §7.2.8：
- L5 矩阵 2–6 阶，数论包含 φ 和、floor/ceil、取模取余、留数定理、0/0 极限；5% 概率多重无穷；另有 ln2 恒等对、加减 0、ζ(4)、Poisson 和、参数联动积分；生成时校验因子乘积与行列式。
- L4 为 4–5 个非 1 分析因子：每个因子由幂积分或几何级数隐藏，不使用矩阵和数论。
- L5 为 64 位种子，唯一含矩阵与数论：0–2 个矩阵、1 个 φ 除数和因子、经典积分/连乘/嵌套极限；矩阵由幺模行列变换打散，没有单列 325 系数。
- 特殊模板包含三重 Gaussian、四次积分乘积、Beta/Dirichlet 平方、Frullani、ζ(2) 二重积分、极坐标、Basel、Euler 乘积、双重 ζ、Möbius、Wallis。
- 随机窗口首次显示时居中到当前显示器工作区，不跟随主窗口位置。
- 325 的系数伪装为立方和比 / 指数对数 / 平方和，不再直接写 325 或 13·25。
- 超出层数/重数预算的槽位变成 0 维装饰因子，不增加积分重数。
- L4 全零 32 位 = 8 个类型 0 + 家族 0/参数 0 → 八个 `∫_0^1`。

## 4. 归一化积分家族

| # | 家族 | fi(x) | 区间 |
| --- | --- | --- | --- |
| 0 | 幂函数 | `(p+1)x^p` | `[0,1]` |
| 1 | 指数 | `a e^{-ax}`，`a=(p+1)/100` | `[0,∞)` |
| 2 | 高斯 | `(2a/√π)e^{-a²x²}` | `[0,∞)` |
| 3 | Cauchy | `2a/(π(1+a²x²))` | `[0,∞)` |
| 4 | 对数幂 | `(p+1)²x^p(−ln x)` | `[0,1]` |
| 5 | Frullani | `(e^{-ax}−e^{-aex})/x` | `[0,∞)` |
| 6 | sinc² | `2/(πa)·sin²(ax)/x²` | `[0,∞)` |
| 7 | Beta | `(p+1)(p+2)x^p(1−x)` | `[0,1]` |
| 8 | 三角 | `(2p+2)sin^{2p+1}x cos x` | `[0,π/2]` |
| 9 | arcsin | `2/(π√(a²−x²))` | `[0,a]` |

- 极限因子：`(n+a)/n`、`1+a/n`、`cos(a/n)`、`e^{a/n}` 等，极限 =1。
- 级数因子：`1/2^k`、`1/(k(k+1))`、`(q−1)/q^k`、`a(1−a)^{k−1}`、
  `(a+1)/((k+a)(k+a+1))`、`1/(2k−1)−1/(2k+1)` 等，和 =1。
- 超出层数/重数预算的槽位不再塞简单装饰因子，直接忽略，避免 `sin²a+cos²a` 这类过于简单的式子。

### 7.2.2 数字多样化（第二轮评审）

评审指出"系数类型太频繁，每次都是它们（尤其在 L1/L2）"。改法：

- **隐藏系数参数化**：`HiddenCore325` 从 8 个固定串改成 6 族 + 参数由种子决定——
  平方差 `(a−b)(a+b)`（325 的三组因数对 → a=163/35/19）、立方和商 `(a³+b³)/(a+b)`、
  对数 `e^{ln u+ln v}`、复数模长 `|a+bi|²·k`（12 组）、平方和 `a²+b²`（6 组）、Vieta 两根之积。
- **L1 模板 10 → 16**：新增 `tan(π/4)`、`sin(π/2)`、`2cos(π/3)`、`sin(π/6)+cos(π/3)`、
  `arcsin1/(π/2)`、`arctan1/(π/4)`、`(arcsin½+arccos½)·2/π`、`sin²+cos²`、`2³/8`、`e^{ln3}/3`、
  `5!/(5·4!)`、`(a+1)²−a²−2a`（a 跟种子走）。
- **L2 极限因子 10 → 14**：加 `tan(a/n)/(a/n)`、`cos²(a/n)+sin²(a/n)`、`sin(a/n)/(a/n)`、`arcsin(a/n)/(a/n)`。
- **种子加长**：L1 8→12 位、L2 16→20 位（L3–L5 不变）。

注意：`e^{ln1+ln325}` 这种会写出裸 325，所以 (1,325) 那组因数对已排除。

### 7.2.3 L5 嵌套层（第三轮评审）

评审要求"积分上下限本身还是积分/级数/极限/连乘，最多随机叠三层"。实现：

- `NestedBound(depth,k)` 递归生成**值已知**的常数表达式当上下限：
  积分 `∫₀^C 2t dt = C²`（继续递归）、级数 `Σ1/2ⁿ = 1`、极限 `(1+1/n)ⁿ → e`、连乘 Wallis `= π/2`。
- 外层模块 `∫₀^B 2x/B² dx = 1` 对**任意** B 成立，所以嵌套再深也不破坏"乘积 = 325"的配平。
- L5 有 50% 概率启用，层数 1–3（`SD(seed,73) % 3 + 1`），内容由种子决定。
- 两套校验器都能算：B 是数值，积分限求值后再积分。

另外补回了 **连乘**（Wallis `(2/π)∏(2n)²/((2n−1)(2n+1)) = 1`）和 **Γ 函数**
（`(4/(3√π))·Γ(5/2) = 1`，C# 用 Lanczos、Python 用 `math.gamma`）。

### 7.2.4 L5 矩阵乘积与自定义种子（第四轮）

- **`det(A·B)`**：复合数因子（如 65=5·13、25=5·5）有 40% 概率写成两个矩阵相乘的行列式。
  利用 `det(AB) = det(A)·det(B)`：C# `NDetProd` 和 Python `DetProd` 各自把两个矩阵的行列式算出来再相乘，
  没有共享代码。质数因子则用幺模矩阵（det=1）配一个 det=因子 的矩阵。
- **自定义种子窗口**（`SeedDialog.cs`）：数字模式/ZC 模式，ZC 只是把 0/1 串按二进制转成十进制数字串，
  之后 `NormalizeSeed` + 生成/映射完全不变。

### 7.2.5 嵌套加深（第五轮）

- 深度 **1~4 层**（`1 + Hash32(seed,73) % 4`），50% 概率启用。
- 每一层都可以再嵌一层，两种运算符按层奇偶分组：
  偶数层 = 积分 `∫₀^C 1 dt = C` / 级数 `C·Σ1/2ⁿ = C`；
  奇数层 = 极限 `C·lim(1+1/n)ⁿ = C·e` / 连乘 `C·∏Wallis = C·π/2`。
- 外层模块 **`∫_A^{A+k} 1/k dx = 1`**：上下限都出现嵌套树，值恒为 1。
- 每层用不同哑变量（n / m / p / q），子式加括号，避免变量捕获与 `∏ A·Σ B·∏ C` 的解析歧义。

这轮踩到并修掉的三个坑：
1. `SD(seed, 73)` 在 64 位种子上越界返回 0 → 深度永远是 1；改用 FNV 哈希。
2. 相邻层同名哑变量互相捕获 → 实测 `lim(4·∏·(1+1/n)ⁿ)` 算出 5e27。
3. `∏` 后面跟 `·Σ·∏` 会被解析成 `∏(A·B·C)`（无穷），把运算符子式加括号解决。

### 7.2.6 连乘多样化（第六轮）

原来 `\prod` 只有 Wallis 一种形态，显得单调。现在 4 种，都用"配一个常数把值拉回 1"的写法：

| 连乘 | 值 | 归一化系数 |
| --- | --- | --- |
| `∏ (2n)²/((2n−1)(2n+1))` | π/2 | 2/π |
| `∏ (n+1)²/(n(n+2))` | 2 | 1/2 |
| `∏ (1 − 1/(n+1)²)` | 1/2 | 2 |
| `∏ (1 − 1/(n+3)²)` | 3/4 | 4/3 |

两处都随机化：经典模块池的 `ProdPick(seed)` 和嵌套层的连乘节点（按 `(k>>2)&3` 选）。
四个值都单独用 `--audit-one` 复核过（2 / 0.5 / 0.75 / 1.5708）。

### 7.2.7 嵌套多样化（第七轮）

嵌套原子从 4 种扩到 **8 种**，外层模块从 1 种扩到 **3 种**，组合起来 24 种基本形态，再乘深度 1~3：

| 原子 | 值 |
| --- | --- |
| `∫₀^C 1 dt` | C |
| `∫₀¹ C dt` | C |
| `Σ C/2ⁿ` | C |
| `C·Σ 1/2ⁿ` | C |
| `C·lim(1+1/n)ⁿ` | C·e |
| `lim(1+C/n)ⁿ` | e^C（仅最内层） |
| `C·∏ Wallis` | C·π/2 |
| `C·∏(1−1/(q+1)²)` | C/2 |

| 外层模块 | 值 |
| --- | --- |
| `|∫_A^B 1/(B−A) dx|` | 1 |
| `|(1/(B−A))·∫_A^B 1 dx|` | 1 |
| `|(2/(B²−A²))·∫_A^B x dx|` | 1 |

`|·|` 只在第 1 种出现（约三分之一），另两种用**有符号**系数，数学上同样恒等于 1：

| 模块 | 是否带 |·| |
| --- | --- |
| `|∫_A^B 1/(B−A) dx|` | 有 |
| `(1/(B−A))·∫_A^B 1 dx` | 无 |
| `(2/(B²−A²))·∫_A^B x dx` | 无 |

为此修了审计器的两个真问题：

1. **积分方向**：C# 原来遇到 `a > b` 会交换端点却不取负，和 Python 的有向积分不一致（同一式子一边 +325 一边 −325）。现在按 `dir = −1` 处理，两个引擎对齐。
2. **上下限同值**：两棵独立树可能恰好同值（同形状同底数），`(B−A)` 变成 0。生成时用闭式值比对，同值就重抽，最多 6 次，仍相同则退化成常数。

三处坑：
1. **符号**：校验器遇到 A>B 会交换上下限但不翻符号，所以三种模块统统套 `|·|`。
2. **数值爆炸**：`e^C` 连续套几层会把值推到 1e20 以上，误差界直接判"未验证"，因此只允许出现在最内层。
3. **ln / 三次方两种模块**实测会让 Python 校验器除零（两边求值有细微差异），已弃用。

### 7.2.8 L5 v2 自然模型 + 旧版融合（2026-10-23）

评审的最终意见是：旧 L5 的“325”仍来自**前端拼接**——大量独立模块等于 1，
真正决定值的是一两个隐藏因子。v2 把 325 变成**中端构造 + 多候选仲裁**的结果；
随后按用户要求把 v2 **嵌回旧 L5 外壳**：嵌套上下限、旧 =1 模块、
行列式乘方都保留，自然模型只负责 325 核心。

流水线（`src/cs/L5Pipeline.cs`）：

```
seed → SHA-256 派生子种子 → 4–8 个候选（M1–M10）
     → 构造性 325 → 融合层（嵌套壳 / 行列式乘方 / 旧 =1 模块）
     → T1–T6 + 选中候选 FormulaAudit
     → 确定性仲裁 + 批内 fingerprint 去重 → 审计链 JSON
```

模型库（完整构造式见 `docs/l5-v2-design.md`）：

| 模型 | 自然路径 | 构造式 |
| --- | --- | --- |
| M1 | 二项式组合计数 | `D=det(M)=26`，`C(D,2)=325` |
| M2 | 等差数列求和 | `n/2(2a+(n−1)d)=325`，`D=n` 用整数和表示 |
| M3 | 平方和 / 格点 | `325=1²+18²=6²+17²=10²+15²` |
| M4 | 星条 / 生成函数系数 | `Σ_{x=0}^{D−1}Σ_{y=0}^{D−1−x}1=D(D+1)/2` |
| M5 | 概率期望 | `D·(1/D)·Σk=D(D+1)/2` |
| M6 | 矩阵迹/行列式对称多项式 | `det(M)+tr(M)²=(325−t²)+t²` |
| M7 | 含参积分 / 梯形面积 | `∫_0^D(a+bx)dx=325` |
| M8 | 级数部分和 / 交错平方和 | `Σ(−1)^{k+1}k²=D(D+3)/2` |
| M9 | 数论函数 / φ-floor | `Σφ(k)⌊D/k⌋=D(D+1)/2` |
| M10 | 线性递推 / 进位展开 | `4⁴+4³+4+1=325` |

关键点：

- 同一候选批次内模型不重复，拓扑覆盖 chain/tree/nested/net/closed；
- 每个候选至少 1 条跨模块边（源模块的值参与最终闭合）；
- **融合层**：`∫_A^B core/(B−A)du`（A/B 是旧式嵌套树）、
  `(core)^{det(M)=1}`（行列式作为乘方）、1–2 个旧 =1 模块
  （Wallis / Γ(5/2) / Möbius / ζ(4) / 三重和 / `∫xeˣ` / `det=1` / Traps…）；
- 只对**选中候选**做 FormulaAudit；未选中候选 `audit_ok=false / audit_mode=skipped`；
- 所有融合因子套不可见 `{}`，否则 `Σ` body 会吞掉后面的因子（实测 325→288.888…）；
- `sha256(canon(expr))` 批内去重，碰撞才 `derive(seed,"retry")`；
- 报告/语料模式用 10 步模型轮换表保证近 10 道题自然路径不重复；
- **L5 的 `Layers` 变为 DAG 节点数（融合后 60–100）**，`Dims` 为 1–6。

新旧对比（40 种子）：T1 0.384→0.154（降 60%）、T2 26/40→0、T4 1.725→0、
T5 0→5.725、近 10 模板重复 39→0；T3 0.832→0.762，T6 0.370→0.416。
200 种子：T1 0.1521、T2=0、T4=0、T5=5.735、T6=0.3839、retry 0、fp 冲突 0。
详情与风险见 `docs/l5-v2-report.md`。

### 7.4 最外层随机（L1–L4 / 旧 L5）

L1–L4 与旧 L5 的最外层四选一：`lim` / `Σ` / `∫` / 因子乘积（`WrapOuterRandom` + 因子链）。
L5 融合版的最外层通常是**因子乘积**：旧外层包装 × 旧 =1 模块 ×
`(嵌套积分壳)^{det=1}`；不再强制四选一。

**行列式外壳已按用户要求移除**（2026-10-21）：之前 L5 有 18% 概率把整条链套进
`\det\begin{pmatrix}<链>&0\\0&1\end{pmatrix}`，数学上等价但那整条式子落在矩阵一个格子里，
观感偏"装饰"，去掉。审计器的**表达式矩阵元**支持保留（整数矩阵仍走 Bareiss 精确消元，
含表达式的走逐元求值 + 部分主元高斯消元），只是生成器不再产生这种形态。

### 7.5 视觉 · 支持矩阵与缩放

WpfMath 实测支持：`\det\begin{pmatrix}`（2–6 阶）、`\mathrm{mod}`、`k!`、
`\left\{/\lfloor/\lceil`、`\oint`、`\prod_p`、`\int\int`、`\left|...\right|`、顶层 `\\`。
**不支持**：`\begin{aligned}`、`\begin{matrix}`、`\substack`、`\bmod`。

**折行功能已删除**（2026-10-21 晚，用户要求）：长式子一律单行渲染，
靠窗口左下角的 `缩小 − / 放大 + / 复位` 与滚轮缩放来看（`MathBox` 支持以光标为中心的
滚轮缩放、左键拖动平移、双击复位）。`--math-test` 会把 17 条探针的
"实际 vs 预期"写成一张表，并做一次 `ZOOM_OK` 缩放自检。
